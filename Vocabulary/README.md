# Vocabulary Bank

This is your personal word bank. Keep it in the form that makes you want to return to it.

## A simple way to use it

- Add new words or useful sentence patterns after studying.
- Review a small part of yesterday's list before adding today’s words.
- Keep words from everyday life if you enjoy them; mark TOEFL or academic words with `#TOEFL` so you can find them later.
- Do not try to make every entry perfect. A word that you can find and revisit is already useful.

## Optional entry format

```
word / phrase — Chinese meaning — one context or sentence — #TOEFL (if relevant)
```
